## Principles

- [DP-001 — One canonical source of truth](principles/DP-001-one-canonical-source-of-truth.md) — each fact lives in one note; everything else links to it.
- [DP-002 — Integrate, don't append](principles/DP-002-integrate-dont-append.md) — a source is split into items and merged into the notes that own them.
- [DP-003 — Match before create](principles/DP-003-match-before-create.md) — search for an existing home before any new note, and get the owner's OK for a new one.
- [DP-004 — Provenance on every ingest](principles/DP-004-provenance-on-every-ingest.md) — notes built from a source record where it came from and when.
